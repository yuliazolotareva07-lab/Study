
# НИР: аудиовизуальный перевод

## Тема исследования

Аудиовизуальный перевод: особенности субтитрирования и передачи культурно-специфических элементов.

## О проекте

Данное хранилище Obsidian используется для организации материалов научно-исследовательской работы в области аудиовизуального перевода.

Основное внимание уделяется субтитрированию, его лингвистическим и техническим особенностям, а также стратегиям передачи культурно-специфических элементов.

## Структура хранилища

- `00_Inbox` — новые идеи и материалы, которые ещё не обработаны;
- `01_Literature` — заметки по научной литературе;
- `02_Notes` — постоянные исследовательские заметки и основные понятия;
- `03_Projects` — план и материалы текущего исследования;
- `04_Drafts` — черновики научного текста;
- `05_Output` — завершённые материалы и результаты;
- `_Templates` — шаблоны исследовательских заметок;
- `_Attachments` — PDF, изображения и другие вложения.

## Основные направления исследования

- аудиовизуальный перевод;
- субтитрирование;
- культурно-специфические элементы;
- переводческие стратегии;
- технические и языковые ограничения субтитров.
